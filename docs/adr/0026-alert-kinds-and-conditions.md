# ADR 0026: Типи сповіщень про ціну й умови спрацювання

- Статус: прийнято (2026-11-08). Модуль 11a; розширює ADR 0010, 0025.

## Контекст
ТЗ 11.1–11.2: сповіщення на маршрут (дати, пасажири, багаж, бажана ціна), на гнучкі дати
(«будь-які вихідні грудня до 100 €»), на житло й на всю поїздку; умови — нижче значення,
зниження на суму чи відсоток; без повторних однакових повідомлень. ТЗ 11.4: тип, який не можна
надійно перевіряти поточними джерелами, не вмикати як робочий.

## Рішення
- **`alerts.kind`**: `flight` (маршрут на дати), `flex` (період вильоту `departure_until`, ночі
  `min_nights`–`max_nights`, `weekends` — виліт чт–сб і повернення сб–пн), `stay` (місто й дати,
  `stay_key` — конкретний об'єкт), `trip` (переліт + житло).
- **Джерело перевірок** — як і раніше `ALERT_PROVIDERS` (кешований Travelpayouts, без квоти
  SerpApi). Воно знає лише дорослих в економі: діти й інші класи в підписці не пропонуються
  (веб пояснює чому). Ціна — за всіх дорослих (Offer.price, ADR 0013); поріг — теж за всіх.
- **Багаж** зберігається (`baggage`), іде в запит і в посилання. Відома кінцева вартість —
  порівнюємо її; невідома — ціну квитків, а повідомлення каже «ціна без урахування багажу»;
  тариф без такого багажу пропускаємо.
- **Житло й поїздка**: `services/alert_sources.py` (найдешевше житло / конкретний об'єкт;
  поїздка = переліт + житло). Підключаються лише за реального джерела житла (`STAY_PROVIDERS`
  не лише mock); `GET /alerts/channels` → `kinds` каже, що можна створити. Зараз — лише
  flight / flex; у вебі житло й поїздка — неактивна кнопка з поясненням.
- **Умови** (`domain/alerts.triggered`): `below_price` (≤ порога), `drop_amount` / `drop_percent`
  (від `baseline_price` — ціни першої вдалої перевірки), `below_typical` (лише flight).
  Повтор — лише при новій істотній зміні: для порога й «типової» — ще −3% від ціни минулого
  сповіщення, для зниження — ще на ту саму суму чи відсоток. Плюс пауза між сповіщеннями й
  налаштування власника (ADR 0025).

## Наслідки
- Міграція 0019 (`alerts.origin` тепер може бути NULL — для житла).
- Повідомлення для flex містять знайдені дати; посилання веде саме на них.
