# ADR 0001: ARQ для фонових задач

- Статус: прийнято (етап 0)

## Контекст
Потрібні періодичні перевірки цін для алертів і пакетні задачі (резюме відгуків).
Кандидати: Celery, ARQ.

## Рішення
ARQ. Він async-native, як і FastAPI/SQLAlchemy async/redis-py: ті самі клієнти й код
працюють без sync-обгорток. Використовує вже наявний Redis, cron вбудований, конфігурації
мінімум.

## Наслідки
- Немає вбудованого моніторингу на кшталт Flower. Стан задач пишемо в логи й Sentry.
- Якщо знадобляться складні workflow (chord, canvas), рішення перегляне окремий ADR.
