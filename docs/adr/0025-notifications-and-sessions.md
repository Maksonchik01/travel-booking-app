# ADR 0025: Налаштування сповіщень, сесії й очищення історії

- Статус: прийнято (2026-11-08). Модуль 10c; розширює ADR 0010, 0011, 0023.

## Контекст
ТЗ 10.8–10.9: налаштування сповіщень (email, Telegram, частота, мінімальна зміна ціни,
тихі години, категорії) і безпека (пароль, способи входу, сесії, вихід усюди, видалення,
очищення історії). Умова — лише робочі перемикачі на реальних даних.

## Рішення
- **`users.notify_prefs`** (JSON `NotifyPrefs`, NULL — за замовчуванням): канали email/telegram,
  `min_interval_hours` 24/72/168, `min_drop_percent` 0/3/5/10 (від ціни попереднього
  сповіщення), тихі години `[quiet_start, quiet_end)` у поясі `timezone` (IANA з браузера,
  без нього — UTC; через північ — 22 → 8), `muted` — категорії `below_price` / `below_typical`.
- Діють на підписки з `alerts.user_id` (створені після входу); анонімні — як раніше.
  Воркер перевіряє ціну завжди, а перед надсиланням `domain/notify.hold_reason` вирішує, чи
  тримати; причина пишеться в журнал (`alert_events.kind = "held"`, `detail`). Глобальні
  правила (лише нижча ціна, `ALERT_MIN_HOURS_BETWEEN_NOTIFICATIONS`) — нижня межа.
  Тиха година не «з'їдає» сповіщення: ціна лишається нижчою — надішлемо на першій перевірці
  після неї.
- **Сесії**: `user_sessions.device` — лише «браузер · ОС» (веб рахує з User-Agent і шле
  `X-Client-Device`; API бере друковані символи до 60), `last_seen_at` — не частіше, ніж раз на
  15 хв. IP не зберігаємо. `GET /account/sessions` (id — 16 символів хешу токена, сам токен не
  розкриваємо), `DELETE /account/sessions/{id}` (поточна — це вихід), `POST
  /account/sessions/end-others`; «Вийти на всіх пристроях» — `/auth/logout?everywhere=true`.
- **Очищення історії**: пошуки (`DELETE /account/history`), розмови з помічником на сервері
  (`DELETE /account/chats`; згода на синхронізацію лишається) разом з їхньою копією в браузері,
  і всі ключі `tickets.*` у localStorage/sessionStorage, крім теми.

## Наслідки
- Міграція 0018. Сторінка конфіденційності описує пристрій сесії й налаштування сповіщень.
- Тихі години точні з кроком перевірки воркера (`ALERT_CHECK_INTERVAL_HOURS`).
