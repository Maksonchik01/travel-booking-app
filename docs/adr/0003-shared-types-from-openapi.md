# ADR 0003: спільні TS-типи генеруються з OpenAPI

- Статус: прийнято (етап 0)

## Рішення
Джерело істини для контракту — Pydantic-моделі FastAPI. `packages/shared` містить лише
згенерований `api.gen.ts` і зручні аліаси в `index.ts`. Ручних дублікатів моделей немає.

## Наслідки
Після зміни API потрібно запускати `make gen-types`. CI перевіряє актуальність.
