# ADR 0058 — TTL за типом даних, без подвійних платних запитів, облік кешу

Статус: прийнято (V3, етап 5). Доповнює [ADR 0034](0034-provider-resilience-and-freshness.md).

## Перевірено без змін

- **Спільний механізм джерел:** усі HTTP-запити — через `ProviderGate` (ліміт одночасних, обмежені повтори 502–504 й
  обриву, 429/4xx без повтору, тайм-аут джерела над ним) і `ApiMeter` (ADR 0055).
- **Єдині формати:** `Offer`, `Stay`, `StayRate`, `SellerOffer`; невідоме — `None`, не нуль. Адаптери пропускають
  некоректні рядки відповіді (тести на записаних відповідях кожного джерела).
- **Ключі кешу** — усе, що змінює відповідь джерела (маршрут, дати й гнучкість, склад, клас, валюта, сусідні аеропорти,
  «лише прямі»); фільтри, профіль, багаж, уподобання — після джерела й у ключ не входять.
- **Дедуплікація:** однакові одночасні запити — один виклик у процесі й замок у Redis між процесами.
- **Поетапний пошук:** гнучкі дати — кандидати з кешованого календаря → живі лише для `FLEX_LIVE_DATE_PAIRS`
  найдешевших пар (ADR 0016); Explore — лише кешовані ціни, житло для 3 найдешевших (ADR 0045); поїздка — до 6
  кандидатів перельотів × ≤ 3 вікна житла (ADR 0009). Дорогі необов'язкові кроки — у `optional_spend()` (ADR 0055).
- **Багатоджерельний пошук:** однаковий рейс — `flight_key` (усі номери рейсів), порівняння цін — `comparable_order`
  (валюта пошуку, відомий багаж; невідоме — у кінці) (ADR 0041).
- **Застарілі дані:** Redis — TTL на кожному ключі; час отримання ціни зберігається в самій пропозиції
  (`collected_at`, `found_at`), тож кеш не «омолоджує» ціну — UI показує справжній вік.

## Змінено

- **Без подвійних платних запитів.** Процес, що чекав на чужий замок (`LOCK_WAIT_S` = 25 с), раніше після очікування
  йшов до джерела сам — а живий пошук триває до 30 с, тож той самий запит міг оплатитися двічі. Тепер для платного
  джерела (`paid`: живі перельоти й житло) — `ProviderError("busy")`; безкоштовне кешоване джерело йде саме.
- **TTL за типом даних:** живі ціни й тарифи продавців житла — `PROVIDER_CACHE_TTL_S` (30 хв); кешовані ціни
  Travelpayouts — `CACHED_SOURCE_TTL_S` (3 год); видача житла — `STAY_CACHE_TTL_S` (1 год; 10 кредитів scrape.do за
  пошук, сторінка об'єкта й тарифи беруть її з кешу).
- **Облік кешу:** `cache:<джерело>:hit|miss` у `api:stats` → `api_spend.cache_7d` у `/ops/summary` (частка влучань).
