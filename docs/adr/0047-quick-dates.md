# ADR 0047 — Швидкі дати й «лише вихідні»

Статус: прийнято (етап 3 розширення).

## Контекст

У календарях пошукових форм потрібні швидкі варіанти:
- найближчі вихідні;
- наступні вихідні;
- будь-які вихідні вибраного місяця;
- поїздка на 3–4 дні;
- поїздка на 5–7 днів;
- гнучкий діапазон дат.

Пошук має перебирати можливі комбінації дат і знаходити пропозиції потрібної тривалості.

Що вже було:
- гнучкі дати й ночі (ADR 0016, модуль 2b): «увесь місяць» / «свій період» + `min_nights` / `max_nights`;
- кешовані кандидати → `check_dates` для живого джерела;
- «лише вихідні» в сповіщеннях flex (ADR 0026, правило чт–сб → сб–пн).

## Рішення

- **Одне правило вихідних** — `domain/flights.is_weekend_trip`:
  - виліт чт–сб, повернення сб–пн, не довше за 4 ночі;
  - ним користуються пошук, поїздка, Explore і сповіщення;
  - для сповіщень додалось обмеження в 4 ночі (раніше, наприклад, чт → пн через тиждень формально теж підходило).
- **`FlightQuery.weekends` / `TripQuery.weekends`** — лише з періодом вильоту туди-назад, інакше валідація відмовляє.
  - Поїздка з точними датами його в переліт не передає: дати вже задані.
  - `_fits_trip` відсікає інші пари дат — і для кешованих кандидатів (`check_dates`), і для видачі.
  - SerpApi без кешованих кандидатів перебирає лише пари пт → нд і сб → пн (бюджет запитів — не на будні).
  - Travelpayouts і mock — фільтр сервісу.
  - Поле входить у ключ кешу.
- **Пресети** — `lib/date-presets.ts` (чисті функції; «сьогодні» — місцевий день, рахується в обробнику кліку, не під час рендеру):

| Пресет | Що заповнює |
|---|---|
| Найближчі / наступні вихідні | точні дати пт → нд |
| Вихідні місяця | місяць обраної дати (якщо не минув), інакше наступний; 1–3 ночі; «лише вихідні» |
| 3–4 дні / 5–7 днів | період 30 днів від обраної дати чи завтра; 2–3 / 4–6 ночей |
| Гнучкий діапазон | наявний «Свій період» у полі гнучкості |

- **Компонент `DatePresets`** — у формах рейсів, поїздки й Explore. Він лише заповнює поля; пошук, як завжди, кнопкою (квоти живих джерел).
- **URL**: `wk=1` (рейси й поїздка; у рейсах — лише разом з ночами).

## Наслідки

- Вихідні в місяці — один пошук: кешовані кандидати + до `FLEX_LIVE_DATE_PAIRS` живих перевірок.
- Без кешованого джерела SerpApi перевіряє лише кілька найближчих п'ятниць і субот (бюджет `SERPAPI_MAX_REQUESTS_PER_SEARCH`).
