# ADR 0029: Стани інтерфейсу, фільтри й мобільна версія

- Статус: прийнято (2026-11-09). Модуль 13a.

## Контекст
ТЗ 13.2–13.4: у кожного асинхронного блоку — початковий стан, завантаження, результат,
порожньо, частково, помилка й повторна спроба, без нескінченного завантаження; фільтри — панель
на десктопі, окреме вікно на телефоні (кількість активних, скинути, застосувати, стан при
поверненні); мобільна версія без горизонтального переповнення й обрізаних кнопок.

## Рішення
- **Тайм-аути**: запити браузера до `/api/*` — `lib/client-fetch.ts` (45 с, чат — 90 с); сервер
  має власні тайм-аути до API. Після тайм-ауту — помилка з повтором, а не вічний спінер.
- **Помилка з повтором**: `components/retry.tsx` (`RetryNotice`, `role="alert"`) — тарифи житла,
  продавці рейсу, ШІ-чат (повідомлення вже в полі — повтор надсилає його знову); результати
  сторінок — `components/page-notice.tsx` з посиланням на той самий пошук (без JS теж).
  Підказки міст розрізняють «нічого не знайдено» й «недоступно» й пропонують ввести код IATA.
  Частково — як і раніше `ProviderAlerts` над результатами (що відповіло, що ні).
- **Фільтри** (`components/filter-shell.tsx`): ≥ lg — липка бічна панель, зміни застосовуються
  одразу; вужче — кнопка «Фільтри · N активних» і повноекранне вікно (`role="dialog"`, Escape,
  фокус на «Закрити» й назад на кнопку, без прокрутки сторінки під ним) з липкими «Застосувати»
  й «Скинути»; у вікні фільтри застосовуються кнопкою. Без JS — панель на сторінці. Стан — в URL.
- **Мобільна версія**: e2e `e2e/mobile.spec.ts` (390 px) обходить головну, результати з деталями,
  житло й карту, поїздку, вхід, юридичні сторінки, усі розділи кабінету й ШІ-чат і падає на
  горизонтальному переповненні (з переліком елементів). Виправлено: декоративний фон hero
  обрізається, навігація кабінету переноситься рядками, навігація шапки на телефоні прихована
  (розділи перемикає рядок режимів).
