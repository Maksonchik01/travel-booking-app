# ADR 0006: живі ціни через SerpApi (Google Flights)

- Статус: прийнято (2026-11-02)

## Контекст
Ціни Travelpayouts Data API — кеш пошуків віком 2–7 днів, тож на сайті продавця ціна
часто інша. Вимога власника: ціна має відповідати реальній. Живий Aviasales Flight
Search API доступний лише проєктам від 50 000 MAU; Kiwi Tequila — за запрошенням;
Skyscanner — комерційним партнерам; Amadeus Self-Service закрито 17.07.2026; Duffel —
під продаж квитків (верифікація бізнесу, $0.005/пошук).

## Рішення
- **Пошук — SerpApi Google Flights** (`FLIGHT_PROVIDERS=serpapi`): ціни на момент
  запиту, повні сегменти й пересадки, точний час прильоту.
- **Календар — Travelpayouts** (`CALENDAR_PROVIDERS=travelpayouts`): у Google Flights
  немає цін по днях місяця; в UI календар позначено як орієнтовний.
- Час Google — місцевий без поясу → пояс з довідника аеропортів
  (`reference/airports.json`, знімок публічних даних Travelpayouts).
- Код аеропорту шукається точно: WAW — лише Шопен, без Модліна (WMI). Код міста без власного
  аеропорту розгортається в усі аеропорти (LON → LHR,LGW,STN,...). Результати додатково
  фільтруються за довідником (`AirportDirectory.route_filter`), так само й у Travelpayouts.
- Сусідні аеропорти: `origin_radius_km` / `destination_radius_km` у запиті (UI шле 150 км)
  додають аеропорти з регулярними маршрутами в радіусі, разом до 8 кодів. Google Flights
  приймає їх через кому в ОДНОМУ запиті, тож квоту це не витрачає. Travelpayouts шукає
  лише по коду з запиту — сусідні там не знаходяться, лише фільтруються.
- Посилання — `google_flights_url` з відповіді (без окремого платного запиту за рейс).

## Наслідки
- **Квота**: 250 запитів/міс безкоштовно. Бюджет на пошук — `SERPAPI_MAX_REQUESTS_PER_SEARCH`
  (за замовчуванням 4); туди-назад = 1 + `SERPAPI_RETURNS_PER_DATE` запитів; гнучкі дати
  перевіряються від найближчих, поки є бюджет. Відповіді кешуються в Redis.
- **Окремі квитки** Google не позначає → `self_transfer=None` (невідомо, без штрафу).
- **Ключ лише в URL** → логери httpx/httpcore не нижче WARNING, Sentry-breadcrumbs чистяться.
- SerpApi отримує дані з Google Flights, а не через офіційний API Google — для
  комерційного запуску умови перевірити окремо.
