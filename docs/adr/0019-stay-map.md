# ADR 0019: Карта житла — MapLibre + OpenFreeMap

- Статус: прийнято (2026-11-08)

## Контекст
ТЗ модуля 6: інтерактивна карта результатів житла з цінами на маркерах, синхронізацією зі
списком, рухом і масштабом, «Шукати в цій області», режимами «Список»/«Карта» (на широких
екранах — поруч), коректно на смартфонах; без вигаданих маркерів для об'єктів без координат.

## Рішення
- **MapLibre GL JS 6.15** (BSD, без ключа) + **OpenFreeMap** (`tiles.openfreemap.org/styles/liberty`,
  безкоштовні векторні тайли з даних OpenStreetMap, без ключа й лімітів). Атрибуція — штатний
  контрол карти. Браузер відвідувача сам вантажить тайли — це зазначено на `/privacy`.
- v6 — лише ES-модуль; воркер (`maplibre-gl-worker.mjs`) збирач Next не підхоплює, тож
  `scripts/copy-maplibre-worker.mjs` копіює його в `public/maplibre/` перед `dev`/`build`
  (у git копії немає), карта — `setWorkerUrl`. Бібліотека вантажиться динамічно лише в режимі карти.
- Маркер — кнопка з ціною за ніч; лише для об'єктів з `latitude/longitude`. Кількість об'єктів
  без координат підписано під картою.
- Синхронізація: маркер → коротка картка й «Детальніше» (повна картка в режимі «Список»);
  список → карта — подія `stay:focus` (`src/lib/map-events.ts`), кнопка «На карті».
- «Шукати в цій області» з'являється лише після руху, який зробила людина, і додає
  `bbox=півд,зах,півн,сх` — фільтр видачі `StayFilters.bbox` (без нових запитів до джерел;
  без координат об'єкт в область не потрапляє).
- Режим `view=map`: на `lg+` — компактний список і карта поруч, нижче — лише карта.

## Наслідки
- Тайли OpenFreeMap — зовнішня залежність без SLA; збій — повідомлення й список лишається.
