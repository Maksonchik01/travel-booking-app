# ADR 0005: скоринг-рушій і Pareto-вибірка

- Статус: прийнято (етап 2)

## Формула
```
cost = price + λ_time · (total_hours − min_hours) + λ_stop · stops + штрафи ризику
```
- `min_hours` — найкоротший відомий час у дорозі серед оцінених пропозицій.
- λ і штрафи — у `apps/api/src/tickets_api/scoring/config.toml` (перевизначення:
  `SCORING_CONFIG_PATH`). Профілі: `budget`, `balanced`, `time_is_money`.
- Штрафи ризику: пересадка < 60 хв, нічна пересадка, окремі квитки — за кожну пересадку;
  виліт 00:00–05:59 за місцевим часом аеропорту — за кожен напрямок.

## Рішення власника продукту
- **Багаж не входить у вартість** (у ТЗ був `baggage_fee`): реальних цін на багаж немає
  в жодного джерела. Умови багажу — лише попередження (`baggage_not_included`, `baggage_unknown`).
- **Невідомі деталі пересадок — лише попередження**, без штрафу (`layover_details_unknown`).
- **Одна пропозиція — кілька номінацій**: показуємо один раз під найважливішою міткою
  (balanced > cheapest > fastest), інші — в `also`. Штучно другий варіант не підставляємо.

## Вибір
- Pareto-множина — недоміновані за (ціна, тривалість, пересадки).
- **cheapest** — мінімальна ціна серед усіх (нічия → менше пересадок).
- **fastest** — мінімальна тривалість (нічия → ціна → пересадки).
- **balanced** — мінімальний `cost` серед Pareto-оптимальних.
- Невідома тривалість → `total = null`, пропозиція може бути лише cheapest.
- Пропозиції не у валюті конфігу (`EUR`) не оцінюються — немає курсів.

## Перевірка
Еталонні набори з вручну порахованими очікуваннями: `apps/api/tests/fixtures/scoring/`.
Зміна ваг = свідомий перерахунок еталонів.
