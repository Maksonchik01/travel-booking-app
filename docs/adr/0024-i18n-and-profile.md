# ADR 0024: Мови інтерфейсу, профіль і особисті налаштування пошуку

- Статус: прийнято (2026-11-08). Модуль 10b; розширює ADR 0011, 0023.

## Контекст
ТЗ 10.5–10.7: історія пошуку з переглядом параметрів, профіль (ім'я, фото, email, мова,
валюта, країна, домашній і улюблені аеропорти) і особисті налаштування пошуку, що
застосовуються до нових пошуків і змінюються для окремої поїздки без зміни глобальних.
Власник: три мови — англійська (за замовчуванням), українська, російська; перемикач у шапці;
фото — ініціали чи Google, у налаштуваннях можна поставити своє.

## Рішення
- **Мова без префікса в URL.** `app/[locale]/…` — кореневий параметр (`next/root-params`),
  `src/proxy.ts` внутрішньо переписує шлях за cookie `NEXT_LOCALE` (нема — `en`). Адреси й
  посилання не змінюються; `generateStaticParams` дає PPR-оболонку для кожної мови.
  Повідомлення — `messages/{en,uk,ru}.json` з однаковими ключами.
- **Мова в профілі** (`users.locale`): перемикач ставить cookie і (з акаунтом) `PUT
  /account/locale`; після входу (пароль, Google) cookie береться з профілю. ШІ-тексти —
  мовою сторінки (поле `locale` у вхідних даних, rules.md п. 5); підказки місць — `en` для
  англійської, інакше українські назви (кирилиця).
- **Профіль**: `PUT /account/preferences` (мова, валюта EUR/USD/GBP/PLN, країна ISO-2, домашній
  і до 5 улюблених аеропортів — лише коди з довідника, інакше `unknown_place`). Країни —
  `GET /places/countries` (коди), назви — `Intl.DisplayNames` мовою сторінки на сервері.
- **Фото**: власне → Google (`users.google_picture`, лише https `*.googleusercontent.com`,
  оновлюється при вході через Google) → ініціали. Власне — `user_avatars` (bytea, RLS) до 300 КБ,
  тип за сигнатурою (PNG/JPEG/WebP, SVG не приймаємо); браузер зменшує до 256×256 перед
  відправкою. Віддає `/api/account/avatar?v=<версія>` лише власнику; фото Google — через
  оптимізатор `next/image`, браузер не ходить до Google. Видалення акаунта видаляє й фото.
- **Налаштування пошуку** (`users.search_prefs`, JSON `SearchPrefs`; порожні — NULL):
  перельоти — клас, багаж, макс. пересадок, бажані авіакомпанії, пріоритет, час вильоту;
  житло — тип, мін. рейтинг, відстань до центру, зручності, безкоштовне скасування, пріоритет.
  Новий пошук (форма без запиту з URL) бере клас, багаж, пріоритет, валюту й домашній аеропорт
  як початкові значення; фільтри — прихованими полями з позначкою (`ParamsToggle`), як збережені
  фільтри видачі (ті важать більше за ключем). Зняти позначку чи змінити поле — лише для цього
  пошуку; профіль не змінюється. Без акаунта налаштувань немає (лише фільтри з браузера).
- **Історія (10.5)**: «Параметри» запису — розбір рядка тими самими парсерами сторінок
  (`lib/entry-details.ts`): маршрут, дати, люди, клас, багаж, бюджет, головні фільтри словами;
  «Зберегти» переносить запис у збережені пошуки.

## Наслідки
- Нові тексти UI — у трьох файлах повідомлень; тести e2e працюють українською (cookie в
  `storageState`).
- Міграція 0017: колонки профілю в `users`, таблиця `user_avatars` з RLS.
- Фото в БД — свідомо (≤ 300 КБ, одне на користувача) замість окремого сховища.
