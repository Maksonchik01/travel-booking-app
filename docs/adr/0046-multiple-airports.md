# ADR 0046 — Кілька аеропортів вильоту й прибуття

Статус: прийнято (етап 2 розширення).

## Контекст

Людина хоче шукати одразу з кількох аеропортів, наприклад «Амстердам, Роттердам, Ейндговен», і до кількох — з одного боку чи з обох. Вимоги:
- multi-select з пошуком за містом, назвою й IATA-кодом;
- вибір «усіх аеропортів міста»;
- видалення окремих аеропортів;
- сумісність із сусідніми аеропортами (`*_radius_km`);
- фактичний аеропорт кожного рейсу в результатах.

## Що дають джерела

- **SerpApi Google Flights**: `departure_id` / `arrival_id` приймають кілька аеропортів через кому (документація SerpApi; ми вже так передаємо сусідні аеропорти й аеропорти міста, ADR 0006). Кілька аеропортів — той самий **один** запит квоти.
- **scrape.do Google Flights**: ті самі параметри (ADR 0043).
- **Travelpayouts**: одна пара `origin` / `destination` на запит. Він безкоштовний, тож запит робиться на кожну пару.

## Рішення

- `FlightQuery.origin_also` / `destination_also` (і такі ж поля в `TripQuery`) — до `MAX_EXTRA_AIRPORTS = 3` додаткових кодів з кожного боку, разом з основним — до 4.
  - Основний код `origin` / `destination` лишається: він потрібен для підписів, історії й житла поїздки (місто `destination`).
  - Валідація: без повторів і без однакового коду з обох боків.
  - Поля входять у ключ кешу джерела.
- `AirportDirectory.airports_for_all(codes, radius)`:
  - спершу перший аеропорт кожного обраного місця (гарантовано), потім решта аеропортів цих міст, потім сусідні в радіусі;
  - разом не більше `MAX_NEARBY_AIRPORTS = 8`, як і досі для одного запиту Google Flights.
- `route_filter` приймає рейс з будь-якого обраного місця (з урахуванням радіуса).
- Історія цін: маршрут — обраний код, з якого рейс фактично летить, інакше основний код запиту (місто, сусідній аеропорт).
- Mock розкладає пропозиції на кожну пару, як справжні джерела.

### Веб

- URL: повторювані `from=AMS&from=RTM&to=BCN`, кома теж приймається (`placeCodes`).
- Форми рейсів і поїздки:
  - основне поле лишається як було;
  - під ним «чипи» додаткових аеропортів (`extra-places.tsx`) з кнопкою «прибрати» й прихованим полем з тим самим `name`;
  - «Ще аеропорт» відкриває те саме поле з підказками: місто з рядком «усі аеропорти», аеропорт або код;
  - уже обрані коди (основний, інший бік) не додаються;
  - «Поміняти місцями» міняє й «чипи».
- Підписи пошуку — `routeTitle` («WAW, KRK → LIS»). Картка рейсу й надалі показує фактичний аеропорт кожного відрізка.

## Наслідки

- SerpApi / scrape.do: кількість запитів не зростає.
- Travelpayouts: запитів більше в стільки разів, скільки пар (до 4×4), без квоти.
- Житло поїздки шукається лише в місті основного призначення. Додаткові аеропорти прибуття — для перельоту (наприклад, BCN + GRO).
- Сповіщення про ціну й календар цін працюють за основною парою.
